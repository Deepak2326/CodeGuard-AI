# Demonstration inputs

These five functions were exported from the held-out NIST Juliet test split after evaluation. `provenance.json` identifies the original archive path, function, label and hash. NIST distributes these fixtures in the public domain / CC0 for claimed foreign rights.

Upload one file in the Code Scanner to exercise actual model inference. They are incomplete standalone programs and must not be executed. Their names identify the source labels, not a guaranteed model result. They are examples from the same synthetic dataset family used for training, not an independent security benchmark.

Regenerate from the repository root:

```powershell
.\.venv\Scripts\python -m scripts.export_examples
```
